# Responsible use

RET is a tool for understanding and extending software **you own**, for learning, single-player modding,
interoperability and preservation. It is published so others can learn the method, not as a way around anyone's
rights or protections.

## What RET is for

- Modding single-player games you legally own, played **offline** while modded.
- Learning how a program or file format works, on your own copy.
- Making programs work together, or keeping old software running.
- Fan projects that credit their creators and are not sold.

## What RET must not be used for

- **Cheating in online or multiplayer games**, or touching any game protected by anti-cheat. RET's recon returns
  **stop** for anti-cheat; respect it.
- **Removing, bypassing or weakening DRM or copy protection.** The mods here leave every protection untouched and work
  beside it.
- **Piracy**: distributing games, game files, extracted assets, generated assemblies, or anything else you do not own
  the rights to. This repository ships none of them, and forks should not either.
- **Harm**: malware, unauthorised access to systems or accounts, interfering with services or other players, or
  anything illegal where you live.
- **Selling** other people's work, including fan art and game assets.

## Built-in limits

- `ret recon` detects anti-cheat (EasyAntiCheat, ACE and others it recognises) and returns **stop**.
- Install scripts never patch the game's own files or executables; they add files beside them, check pinned
  checksums, and record exactly what they add so it can be removed.
- Nothing extracted from a game is written into the repository; work output goes to a separate folder.

## Your responsibility

Laws on reverse engineering differ between countries, and software licences (EULAs) often restrict it. Some places
allow it for interoperability or research; others are stricter. Check what applies to you and to the program you work
on. **You are responsible for how you use this code.** It is provided "as is", without warranty and without liability
for the authors ([LICENSE](LICENSE)). The authors do not support, help with, or accept contributions toward any of the
uses listed above.
